# wcag-qa-checklist

A lightweight, zero-dependency browser checklist I built to speed up manual QA, cross-browser verification, and accessibility audits before shipping client websites.

## Features

- Categorized checks for **Accessibility (WCAG)**, **Cross-Browser Layout**, and **Load Performance**
- Persists progress in `localStorage` so checks aren't lost on refresh
- Live completion counter and quick reset

## Usage

Open `index.html` directly in any browser — no build step required.
